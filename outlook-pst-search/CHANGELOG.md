## 2026-11-27

- 검색 결과와 AI 근거 카드에 발신자·수신자·첨부를 함께 표시하고, 파일명이나 제목이 맞으면 본문 발췌도 보여줍니다.
- Outlook에서 열려 있는 PST를 단일 파일·폴더 보관함에서 자동으로 읽고, 색인한 첨부를 바로 열 수 있습니다.
- AI 답변의 상세도·진행 내역·인용 우선 근거 목록을 제공하고 DeepSeek 응답에서 추론 블록을 걸러냅니다. 메일 원문과 첨부 미리보기, API 연결 상태 표시를 개선했습니다.
- 입력 중 검색어를 추천하고 빠른 검색 결과를 미리 표시합니다. SQLite 읽기 연결을 재사용하고 문서·첨부를 기본 2개 워커로 병렬 추출합니다. 기존 색인을 그대로 사용하며 `MAILSEARCH_EXTRACT_WORKERS`로 워커를 1~4개 지정할 수 있습니다.

- 사내 AI 답변의 묶음 출처와 별표 목록을 지원하고, 스트림을 읽을 때마다 남은 시간 한도를 적용합니다.
- 사내 AI가 답변 초안을 스트리밍하고 완료된 마크다운의 출처 번호로 원문을 엽니다. 최근 대화를 이어가고, 필요한 메일 스레드와 첨부 본문을 검색 범위 안에서 추가로 찾습니다.
- 사내 AI의 재작성 검색에서 결과가 없으면 원래 검색 조건으로 다시 찾습니다. Windows 게이트웨이에서 유휴 연결이 끊기면 재시도가 허용된 요청에 한해 새 연결로 한 번 다시 시도합니다.

## 2026-11-26

- 사내 AI 답변 진행 단계를 실시간 표시하고 서로 다른 대화의 요청을 병렬 처리합니다. 게이트웨이 연결을 재사용하고 검색어 임베딩·질문 재작성 캐시를 적용하며, 재작성으로 좁혀진 검색 범위에서 원본 후보를 다시 조회합니다.

- USearch 색인을 디스크에 유지해 재시작 후 바로 사용하고, 여러 보관함의 벡터와 좁은 날짜·발신자 범위의 FTS를 조회하는 경로를 개선했다.
- 메타데이터를 포함한 임베딩, 회신 결정 구간 검색, 최대 80개 후보 재정렬, 선택형 로컬 질의 분해, 4천·1만 2천·2만 4천 자 근거 프로필을 적용했다.
- 후보 재정렬 타임아웃을 15초로 늘리고, 사내 게이트웨이 질의 분해와 하위 질의 일괄 임베딩을 지원하며, 회신 근거는 질문 키워드 일치 수를 우선한다.
- 최신 결정 질문에서 날짜를 제한적으로 반영하고, 480자 검색 구간을 최대 1,400자의 연속 원문으로 확장한다.
- 복합·결정·이력 질문에서 같은 보관함 및 기간 안의 추가 근거를 한 번 찾고, 확인되지 않은 항목을 답변에 표시한다.
- 동일 첨부 임베딩과 리랭크·답변 슬롯을 공유하고 사내 그룹웨어의 한국어 인용 구분선을 추가했다.
- 새 검색 구간을 1,100자로 구성하고 최대 1,800자의 연속 원문을 사용하며, 추가 검색에서 신규 근거에 최대 네 자리를 배정한다.
- 사내 게이트웨이의 일반 메일·문서 답변을 원클릭으로 제공하고, 원문 발췌 기반 누락 진단, 2차 벡터 검색과 통합 재정렬, 기본 64,000바이트 근거 예산을 지원한다. 일반 외부 API와 PCF는 근거 검토 후 전송한다.
- PDF·XLS 선택형 추출 폴백과 `.mailsearchignore`를 추가하고, 미지원 파일을 누락에서 제외한다. PST 잠금과 권한 오류를 구분하고, 의미 색인에서 파일명과 짧은 구간을 생략하며 사내 API 배치 기본값을 64로 높였다.
- Windows에서 PDF·XLS 판독기를 자동으로 준비하고, 설치 폴더 감지와 문제 목록의 폴더 제외·갱신 버튼을 추가했다. CMD는 색인 진행률과 임베딩 오류 코드를 실시간으로 표시한다.
- 임베딩 오류가 발생하면 배치를 줄여 재시도하고, 계속 거부되는 구간은 키워드 검색에 남겨둔 채 의미 색인을 이어간다. 로컬 Ollama가 종료되면 다음 요청에서 다시 시작하며 이전에 저장한 임베딩은 재사용한다.
- 보관함 카드에 메일·첨부·문서·PST별 누락과 부분 색인 건수를 표시하고, 상세 사유와 보류 PST 목록을 펼쳐 볼 수 있게 했다.
- 수신자를 답변 근거와 리랭킹에 포함하고, 제목의 호선 번호와 메일 헤더 인용으로 교신 업체를 확인할 수 있게 했다. 납기·금액은 계속 본문이나 첨부에서 검증한다.
- 이메일·도메인을 포함한 자연스러운 업체 답변을 검증하고, 사내 AI 후속 질문에 이전 인용을 연결한다. 메인 화면은 검색과 AI 답변 두 버튼으로 정리했다.

### 자료 보관함 섹션 분리
- 사이드바를 메일 · 문서 · PCF 세 섹션으로 분리 — 각 섹션마다 전용 추가 버튼과 경로 안내(placeholder). 소스 카드에 종류별 건수 표시, 섹션 배치는 최빈 종류 기준.

### PCF 탭 (선주 교신문)
- 파일명에 `PCF`가 들어간 문서를 자동 분류해 전용 탭에서 검색 — 문서 탭·메일 탭과 분리.
- 선주 COMMENT로 과거 실적호선 PCF에서 유사 COMMENT 검색 → 발행·회신·종결 흐름(인접 문맥 포함)으로 근거 수집 → 과거 처리 이력 기반 권장 회신 제시(PCF 전용 지침).
- 문서·PCF 탭의 검색 범위에서 메일 전용 조건(발신자·수신자·첨부) 숨김.

### 메일·문서 탭 분리
- 검색창 위 **메일 / 문서 탭** 추가 — 메일 탭에서는 문서가, 문서 탭에서는 메일이 검색되지 않음. 선택은 브라우저에 유지.
- `mails.kind` 컬럼 추가(기존 색인은 시작 시 파일 확장자로 자동 분류), `filters.tab`이 일반 검색·AI 근거 검색 모두에 적용.

### 설계 이력 질문 (PRD 02 · 2단계)
- `/api/design/preview`·`send`: 근거 1차 검색 + 부족 시 추가 검색 1회, 같은 메일·문서의 인접 문맥 확장, 발췌 예산 5×2,400자.
- 설계 지침(제안/정식 승인 구분, 미확인 명시, 상충 병기)과 시제품/양산 범위 검증 — 시제품 근거로 양산 승인을 주장하면 해당 주장 차단.
- 수치 차이·합계·최댓값 질문은 원문 저장값으로 즉시 계산(두 위치 각각 인용, 외부 전송 없음).
- 답변 범위 선택(특정 보관함), 같은 API로 근거 후보를 재정렬하는 실험 경로(`rerank`).
- 가상 인수 시나리오(시험 보고서·시제품 승인 메일·양산 BOM 3T·전 모델 초안) 통과 테스트.

### 검수 자동화 (PRD 02 · §7)
- `tools/eval_design`·`eval_corpus`: 한국어 합성 10 시나리오로 근거 적중률 측정(발췌 기준 80%, 상위 10건 90% 실측).

### 스캔 PDF OCR (PRD 02 · 3단계 일부)
- 텍스트 30자 미만 페이지만 Tesseract(kor+eng→eng 폴백)로 OCR, `N페이지(OCR)` 위치 색인, 저신뢰 결과 버림, 도구 없으면 기존 동작 유지.

### 독립 문서 검색 (PRD 02 · 1단계)
- 문서 파일·폴더 등록: PDF(페이지)·DOCX(본문)·XLSX(시트·셀)·TXT를 위치 보존 색인, 메일과 한 검색창에서 조회. 인용이 `양산 BOM!F18` 같은 셀 위치를 연다.
- 구형 DOC·XLS는 LibreOffice 설치 시 읽기 전용 변환, 미설치·실패는 상태로 표시.
- 문서 지문은 내용 해시 기반(수정시각 무관) — 갱신 시 변하지 않은 문서의 색인·임베딩 재사용.

### 검색
- Enter 일반 검색이 단어(FTS)+의미(임베딩) 하이브리드로 동작. 임베딩 서버가 없으면 키워드만.
- 검색 결과마다 매치 이유 표시 — 일치 단어·임베딩 유사도·매치 문장 강조 스니펫.
- 답변 제공자 선택 제거, AI 답변은 항상 외부 API가 작성(임베딩은 로컬 유지).
- Ctrl+Enter 두 단계: 1회는 단어+의미 검색, 같은 질문으로 재실행하면 AI가 근거를 정리.
- 따옴표 정확 검색 추가: `"단어"` 포함 메일만 검색, `"A" & "B"`(모두), `"A" or "B"`(하나라도) 연산.
- 검색 범위 필터 개편: 보관함·폴더 제거, 주제·본문·첨부 여부 추가(기존 발신자·수신자·기간 유지).

### AI 연결
- 사이드바에 로컬 AI·외부 API 연결 상태 표시(연결 시 모델명 표기).
- 외부 API 질문(Ctrl+Enter 포함)이 전송 검토 다이얼로그 없이 자동 전송. AI 답변의 "외부 API" 배지 제거.
- bge-m3 임베딩 모델을 저장소에 분할 포함(95MB×12조각, 첫 실행에 결합·SHA-256 검증). setup이 Ollama 자동 실행을 해제하고, 임베딩이 필요한 순간에만 백그라운드로 시작해 앱 종료 때 함께 종료.
- z.ai 등 Anthropic Messages 호환 게이트웨이 지속 개선(의미 검색 근거 사용).

### 성능
- 갱신 증분 색인: 서명이 같은 PST는 재추출 생략, 내용이 같은 메일은 색인·첨부·임베딩 행을 이전 버전에서 복사. 새 메일만 색인/임베딩.

### 배포·UI
- readpst 0.6.76 휴대용 번들(`vendor/readpst-win64`) 저장소 포함 — MSYS2 수동 설치 불필요.
- Git for Windows에 포함된 pdftotext 자동 탐지 — PDF 색인을 위해 별도 설치가 필요 없는 경우가 많음.
- `setup-windows.cmd` 첫 실행 자동 구성(파이썬 winget 설치, 번들 readpst 확인, Ollama 선택), `start.cmd` 원클릭 실행.
- `Ctrl+Enter` AI 질문 단축키(Enter=일반 검색), "검색 시작하기" 카드 제거.
- `start.vbs` 창 없는 실행, 브라우저 탭을 모두 닫으면 앱 자동 종료.
- 보관함 카드에 마지막 색인 뒤 바뀐 PST를 갱신 대상으로 표시.
- 폴더 등록 시 내부 PST 자동 가져오기(빈/깨진 PST 건너뛰고 누락 표시).
